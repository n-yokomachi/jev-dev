jev-dev affectus

この zip だけで動きます。必要なのは macOS と Node 24 以上だけで、 Go のビルドも npm install も要りません。まず「3ステップで起動」まで進んでください。

これは何

同じ発言を2つの判定器に判定させて、並べて見るデモ

ひとつの発言に対して、TypeSafe の jev と LLM（Claude Haiku 4.5）が それぞれ「エージェントの感情が8軸どう動くか」を判定します。その判定を affectus（感情状態エンジン）に別々に積み、 分岐した状態それぞれで返答を生成します。

見たいのは2つ。判定がどれだけ食い違うかと、どちらがどれだけ速いかです。 さらに、判定の差が返答の口調の差として現れます。

LLM

構造化出力で8軸の数値を一度に返す。文章も書ける普通のモデル。実測 1.1 秒前後。

jev

8問を1リクエストで並列に。型付きの値と確率分布だけを返し、文章は一切生成しない。実測 0.7 秒前後。

仕組みを先に知りたいときは、隣の EXPLAINER.html を開いてください。 affectus が何を持っている道具なのか、1ターンで何が起きているのかを図で説明しています。 さらに踏み込むなら docs/ に設計書と実装計画があります。

必要なもの

Node 24 以上だけ

もの要る？なぜ
macOS 必須 affectus がファイルロックに syscall.Flock を使うため、Windows では動きません
Node 24 以上 必須 .ts の型注釈を Node 自身が実行時に外します。ビルド工程がありません
Go 不要 bin/affectus をビルド済みで同梱（x86_64 + arm64 の universal binary）
ネットワーク越しの依存解決 不要 node_modules/ を同梱済み
Vercel AI Gateway の API キー 必須 下の注意書きを参照。zip によっては同梱済みです

Node のバージョンはこれで確かめられます。

node -v

24 未満、またはそもそも入っていない場合は nodejs.org から入れてください。 setup.sh も冒頭で検査して、足りなければそこで止まります。

API キーについて

zip のファイル名に -withkey が付いていれば .env.local が同梱されていて、 キーの用意は要りません。setup.sh もキー入力を飛ばします。

付いていなければ自分のキーが要ります。Vercel のダッシュボードで AI Gateway のキーを発行し、setup.sh が最後に出す案内のとおりに .env.local へ書いてください。 キーの値をターミナルの履歴に残さない書き方を案内します。

起動

3ステップ

01

展開して、そのディレクトリに入る

Finder でダブルクリックして展開したあと、ターミナルでその中へ移動します。

cd ~/Downloads/jev-duel-<日付>
02

セットアップ

何度実行しても同じ結果になります。Node の検査、affectus の確認、感情状態の初期化までを行い、 キーが無ければ最後に書き方を案内します。 

bash scripts/setup.sh
03

起動して、ブラウザで開く

http://localhost:8787 が開きます。8787 が埋まっていれば PORT=9000 のように前置きして変えられます。起動時に実際の URL が出ます。 

node --env-file=.env.local src/server.ts

止めるときはターミナルで Ctrl+C。

使い方

書いて、送る。それだけ

中央のテキスト欄に user としての発言を書いて「メッセージを送信」を押します。 API を叩くのはこのボタンだけで、自動で送信される経路はありません。

会話を重ねるには、同じ欄に次の発言を書いて送り直します。感情状態は送信のたびに両側へ積まれていきます。 比較をやり直すときは右上の reset で両方を初期値に戻します。

画面の読み方

左が LLM、右が jev
同じ発言を同時に判定させ、先に返ったほうから埋まります。
プルチックの輪
affectus に積み上がった現在の感情状態。花弁の長さが各軸の強さで、円に届けば 1.0。 円の外に同じ色で軸名が添えてあります。左右で形が違えば、判定が食い違ってきた証拠です。
中央の対比
軸ごとに1行。中央が 0、左右の末端が 1.0 で、左が LLM、右が jev。 棒の長さがその軸をどれだけ動かしたかです。軸名とその軸の差は、左右の棒に挟まれた中央に上下に重ねてあります。
符号は色
正はその側の色、負はくすんだ灰。長さが同じで色が違えば、両者は正反対の判断をしています。 長さだけ見ていると「片方が大きく動いた」としか読めない場面です。
判定 / 生成の ms
上が判定、下がそのあとに走る返答生成。生成は両側とも同じ Haiku 4.5 なので、 速度差として読むのは判定のほうです。
人格（画面上部）
返答を生成する話し手の性格。friendly（明るく協力的）と contrarian（天邪鬼）があり、 両側とも同じ人格を使います。判定には人格を渡しません。
判定の入出力（JSON）
パネルの一番下に常に出ています。そのターンでモデルに渡した内容と返ってきた内容がそのまま読めます。 返答生成の入出力は出しません。
お金

1ターンあたり約 $0.0035

送信1回で4回のモデル呼び出しが走ります。実測値です。

呼び出し回数実測コスト実測レイテンシ
jev 判定1$0.000082693 ms
LLM 判定1$0.0010671,113 ms
返答生成2$0.001182 × 21,500〜2,600 ms

ざっくり300ターンで $1 ほど。ボタンを押したときしか走らないので、 開いたまま放置しても課金されません。

判定だけを見ると jev は LLM の約 13分の1 のコストで、しかも速い。 これがこのデモで一番見たかった数字です。

困ったとき

詰まりやすいところ

「開発元を検証できないため開けません」と出る
ネット越しに受け取ったファイルに macOS が付ける隔離属性です。setup.sh が 自動で外しますが、手で外すなら展開先のディレクトリで xattr -dr com.apple.quarantine . を実行してください。
ポート 8787 が埋まっている
PORT=9000 node --env-file=.env.local src/server.ts のように変えられます。 起動時に実際の URL が出ます。
起動はするが判定が失敗する
画面の上部にエラーが出ます。多くはキーの問題です。.env.local に AI_GATEWAY_API_KEY= の行があるか、値が空でないかを確かめてください。 Vercel 側で支払い方法が未登録だと 403 が返ります。
Node のバージョンが古いと言われる
24 未満では .ts をそのまま実行できません。node -v で確認して入れ直してください。 nvm を使っているなら nvm use 24 を忘れずに。
輪が両側とも動かない / 変な値が積まれた
画面右上の reset で両方の感情状態を初期値に戻せます。 状態の実体は state/jev.json と state/llm.json です。
Windows で動かしたい
できません。affectus がファイルロックに syscall.Flock（Unix 専用）を使っており、 コンパイルの時点で通りません。

どこに何があるか

場所中身
src/server.tsHTTP サーバー。フレームワークなし、node:http だけ
src/judges.tsjev / LLM それぞれの判定呼び出し
src/affectus.tsaffectus バイナリを子プロセスとして呼ぶラッパー
src/reply.ts感情状態で色づけた返答の生成
src/constants.ts問いの文・軸定義・単価・変換係数・人格。挙動を変えたいときはまずここ

bin/affectusaffectus 本体（universal binary）

docs/superpowers/設計書と実装計画
test/テスト。npm test で全件
触るなら

知っておくと事故らないこと

  • ビルド工程はありません。Node 24 が .ts の型注釈を実行時に外します。 TypeScript コンパイラや tsconfig.json を足さないでください
  • テストは node:test。npm test で全件走ります。 テストフレームワークを足さないでください
  • 依存は ai と zod だけ。UI はフレームワークなし。バンドラも入れないでください
  • 感情の軸は常にこの8つ、この順序。 joy, acceptance, fear, surprise, sorrow, disgust, anger, expectancy
  • LLM 側の配信元は anthropic に固定してあります。 レイテンシ比較の条件を揃えるためなので外さないでください
  • affectus のグローバルフラグはサブコマンドの前に置きます （affectus --config P --state P feel '<json>'）
API キーの扱い

キーの値をコード・コミット・ログ・標準出力のいずれにも出さないでください。 .env.local は .gitignore 済みです。

この zip にキーが同梱されている場合、この zip を持っている人は誰でもそのキーで課金できます。 取り扱いに注意し、漏れた疑いがあれば Vercel のダッシュボードでキーをローテートしてください。
